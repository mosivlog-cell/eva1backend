Evidencia técnica — Pixel Arcade

Proyecto Django de la Evaluación Sumativa 1 (Programación Back End). Sitio informativo de una tienda de videojuegos, sin base de datos, con dos aplicaciones y datos en JSON.

1. Descripción general

Pixel Arcade presenta el catálogo de una tienda de videojuegos en La Serena y un mural de novedades (lanzamientos, torneos y ofertas). Toda la información se lee en las vistas desde archivos JSON y se envía a plantillas Bootstrap locales mediante herencia de base.html.

2. Estructura de carpetas

eva1backend/
  config/                 proyecto Django (settings, urls con include)
  inventarioApp/          app 1: inicio y catálogo
    data/productos.json
    urls.py, views.py
  novedadesApp/            app 2: listado y detalle de novedades
    data/novedades.json
    urls.py, views.py
  templates/               base.html + plantillas hijas
  static/images/           Bootstrap local, CSS propio e imágenes
  venv/                    entorno virtual (sin modificar)
  manage.py
  requirements.txt

3. Herramienta de IA

Se usó el asistente de Cursor (modelo Grok) para diseño de interfaz, HTML/Bootstrap y carga de JSON, según lo pide la pauta.

4. Prompts utilizados (síntesis)

Prompt 1 — Alcance y rúbrica: crear una página web simple y estética manteniendo el esqueleto del proyecto (venv, templates, config, static) y respetar el PDF de la evaluación y el Excel del instrumento para puntaje máximo. No cambiar nada hasta aprobar el plan.

Respuesta incorporada: plan de dos apps, JSON, include(), Bootstrap local, herencia de plantillas y evidencia de IA. Se evitó tocar el venv y se respetó Bootstrap ya copiado en static/images/css y static/images/js.

Prompt 2 — Tema: cambiar el tema a una tienda de videojuegos.

Respuesta incorporada: el sitio se llamó Pixel Arcade; inventarioApp quedó para inicio/catálogo y se creó novedadesApp para eventos y lanzamientos.

Prompt 3: “ok ahora procede”.

Respuesta incorporada: implementación completa: settings (DIRS y STATICFILES_DIRS), urls con include(), vistas que procesan JSON con ciclos y condicionales, plantillas, CSS y evidencias.

5. Cómo se integró en el código

  • Interfaz: navbar, encabezado y pie en templates/base.html; estilo oscuro en static/images/css/estilos.css; Bootstrap minificado local (no CDN).
  • JSON: json.load en las vistas; recálculo de precio con descuento, conteo de stock y filtros por plataforma o tipo.
  • Imágenes locales servidas con {% static %} en ambas aplicaciones.
